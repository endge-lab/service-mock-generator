- Самостоятельный Mock Generator `0.1.0`: JSON Schema Draft 2020-12 subset, default-v1/PCG, local refs, relations, финальная validation, bounded jobs и in-memory sessions.

## Найденные дефекты и исправления

- Fuzzing нашёл расхождение regex parser и стандартного validator для quantifier с leading zeros (`^0{000}$`). Сохранён минимальный corpus; неканоническая запись отклоняется. Повторная campaign нашла escape в конце character-class range (`^[0-\\70]$`); неподдерживаемые class escapes теперь отклоняются до parsing диапазона, второй corpus также сохранён.
- Ограничены крайние отрицательные numeric exponents до compilation; budgets применены к literal const/enum/examples/default, а также полному root после relations.
- Optional source sections relations создаются до записи зависимых target fields.
- Медленный Stop RPC больше не освобождает admission преждевременно: cleanup удерживает квоту до завершения bounded RPC.
- `started` использует текущий parametersVersion после PATCH готовой сессии.
- Backend начинает расчёт lease до upstream subscribe acknowledgement, не добавляя сетевую задержку к обещанному TTL.
- Каждый найденный дефект закреплён regression-тестом. Частичные batches не выдаются.

## Предыдущие нагрузочные запуски

Первый 900-секундный mixed phase выполнил 31 112 lifecycle cycles; сессии/jobs/буферы вернулись к нулю, но итоговая проверка goroutine завершилась ошибкой: cold backend baseline 8, final 21. Harness был дополнен прогревом после рестартов и сохранением стеков; первоначальный запуск не считается успешной приёмкой.

Несколько параллельных повторов завершились клиентским `EADDRNOTAVAIL`: прежний harness открывал новый TCP для каждой команды и исчерпал локальные исходящие порты. В исправленном harness команды используют постоянный пул максимум из пяти HTTP connections (main + четыре workers), SSE остаётся отдельным соединением. Retry mutations не добавлен. Прерванный прогон после дополнительной правки generator также не включается в успешные результаты.

## Поставка и оставшиеся границы

В service-kit-go подготовлена поддержка `postgres.enabled: false` для следующего release (плановая `0.5.0`). Local go.work уже использует её. Самостоятельный Mock build компилируется с опубликованной зависимостью `0.4.0`, однако standalone startup/production image delivery требует отдельно опубликовать kit и обновить Mock dependency. Публикация, commit, tag, push и remote deployment не выполнялись.

Production требует OIDC verification и gRPC TLS; network tests используют loopback и synthetic fixtures. Проверки не заменяют проверку production certificates/IdP и не обещают устойчивость при произвольной нагрузке. Fiber unary requests ограничены RPC/generation deadlines; disconnect не предоставляет отдельный application cancellation context. SSE disconnect/write deadline проверен реальным TCP.

Новые root rules: `MOCK-OWNERSHIP-001`, `MOCK-IDENTITY-001`, `MOCK-LIFECYCLE-001`. Workflow skills не менялись. Отдельного Mock узла в Scope Registry пока нет; для этой задачи применяется существующий backend scope. Добавление отдельного узла — отдельное изменение структуры реестра.
